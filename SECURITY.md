# RangeLink32 Security

RangeLink32 is intended for ESP32 hardware and Wi-Fi networks you own or are authorized to administer.

The initial admin and AP credentials are development defaults only. Change them before regular use.

The final security milestone will protect saved upstream Wi-Fi credentials, require administrator re-authentication before any credential reveal, and keep Internet access policies separate from simple Wi-Fi association.

Do not publish real Wi-Fi passwords, private network inventories, tokens or personal device identifiers in public issues.
